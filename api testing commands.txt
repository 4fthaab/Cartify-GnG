# 🧩 TEST WORKFLOW OVERVIEW

**Sequence:**
1️⃣ `/cart/login` → Link cart and user
2️⃣ `/shopping-list/create` → Upload item list
3️⃣ `/path/optimize` → Generate optimized path for store
4️⃣ `/cart/detect` + `/cart/weight` → Add 3 items to cart
5️⃣ `/cart/detect_remove` + `/cart/weight_remove` → Remove 1 item
6️⃣ `/cart/view` → Verify final cart contents
7️⃣ `/cart/checkout` → Checkout and generate receipt link
8️⃣ `/cart/receipt/{order_id}` → View receipt
9️⃣ `/cart/logout` → Clear temp data

---

## 🧾 Step 1: `/cart/login`

**Purpose:** Link the physical cart (CART102) with user (U123) and store layout (STORE001)

```
POST /cart/login
```

**Body:**

```json
{
  "cart_id": "CART102",
  "user_id": "U123",
  "store_id": "STORE001"
}
```

✅ **Expected Response:**

```json
{
  "cart_id": "CART102",
  "user_id": "U123",
  "linked": true,
  "login_time": "2025-11-06T18:45:00Z"
}
```

## 🧾 Step 4: Add 3 items (camera + weight)

**Purpose:** Simulate adding 3 items into the cart.

---

### 4.1️⃣ Add *Brush*

```
POST /cart/detect
```

```json
{
  "cart_id": "CART102",
  "detected_label": "Brush",
  "camera_confidence": 0.93
}
```

Response:

```json
{
  "detection_id": "D001",
  "candidate_items": [...],
  "status": "awaiting_weight"
}
```

→ copy `"detection_id": "D001"` and use in next:

```
POST /cart/weight
```

```json
{
  "cart_id": "CART102",
  "detection_id": "D001",
  "weight_g": 52
}
```

✅ Response:
`status: "verified"`, and cart now contains Brush.

---
